# ゼミナール倫理 設例1〜7

特定社会保険労務士 特別研修 ゼミナール（倫理）設例1〜7の準備資料ページです。
動画・スライド・詳細解説・討論音声を1ページにまとめています。

## 公開手順（ブラウザだけで完結）

1. GitHubで新しいリポジトリを作る（例：`rinri-seminar`）。Pagesを無料プランで使う場合は Public にする
2. リポジトリの「Add file」→「Upload files」を開く
3. このフォルダの中身（ファイル全部）をまとめてドラッグ＆ドロップし、「Commit changes」
4. 「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` ／ `/(root)` にして Save
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で表示される

## ファイル構成

- `index.html` … ページ本体（サムネイル画像を埋め込み済み）
- `jyunin.mp4` … 動画「棒人間社労士の倫理の旅：20条〜22条」
- `jyunin-audio.mp4` … 討論音声（音声のみのmp4）
- `slides.pdf` / `kaisetsu.pdf` … ダウンロード用PDF
- `slides-XX.webp` / `kaisetsu-XX.webp` … ページビューア用の画像
- `poster.webp` … 動画の表紙画像
